# 🧾 Execução — memórias de sessão do Claude Code

> [!info] O que é esta pasta
> A **memória de execução contínua** de cada sessão de construção da Plataforma (regra 8 do [[CLAUDE - Regras do Claude Code (repo)]]): decisões técnicas, arquivos criados/alterados, comandos rodados, erros e como foram resolvidos — escrita ENQUANTO o Claude Code executa.
> Até 17/09/2026 ela vivia em `docs/execucao/` na raiz do repo; foi unificada aqui no cofre. **Novas sessões escrevem `SESSAO-NN.md` nesta pasta.**
>
> Diferença para os [[TEMPLATE - Handoff de Sessao|handoffs]] em `Handoffs/`: o handoff é o resumo para o dono revisar; a memória de execução é o diário técnico completo da sessão.
