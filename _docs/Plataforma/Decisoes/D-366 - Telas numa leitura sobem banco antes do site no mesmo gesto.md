# D-366 · ⏳ PROVISÓRIA — Telas numa leitura sobem banco antes do site no mesmo gesto (18/11/2026, SESSAO-55)

Subida da SESSAO-55: **banco antes do site, no mesmo gesto.** As atualizações só criam função (o site de hoje nem as chama); o site novo precisa delas — não há caminho de reserva para o banco velho. Origem: provisória 9 da SESSAO-55 ([[handoff_2026_11_18_sessao55_telas_numa_leitura|handoff]]).

**Por que provisória:** Escolha da sessão, feita sem o dono na conversa (fila do Escritório). Vale até o dono confirmar ou mudar.
