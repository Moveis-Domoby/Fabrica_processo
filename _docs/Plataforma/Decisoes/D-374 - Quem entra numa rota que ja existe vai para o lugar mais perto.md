# D-374 · Quem entra numa rota que já existe vai para o lugar mais perto (23/11/2026, SESSAO-56)

Quem entra numa rota que já existe (reprogramar, programar sozinho, parada avulsa) vai para **o lugar onde o caminho aumenta menos**, sem mexer na ordem dos outros; sem ponto no mapa, vai para o fim. ↩️ Revê o "noutro dia/caminhão vai para o fim" de [[D-109 - A ordem das paradas a sugestao e a do mais perto mas qualquer|D-109]]. Resposta do dono nos ajustes da SESSAO-56 (23/11, [[handoff_2026_11_23_sessao56_busca_geoapify_ordem_da_rota|handoff]]).
