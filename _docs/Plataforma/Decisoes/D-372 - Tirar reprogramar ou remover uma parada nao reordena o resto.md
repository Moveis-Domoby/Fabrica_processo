# D-372 · Tirar reprogramar ou remover uma parada não reordena o resto da rota (23/11/2026, SESSAO-56)

Tirar um pedido, reprogramar ou remover uma parada **tira só aquele item**: os outros ficam na ordem que a tela mostrava (ela vai junto no gesto). Do pedido do dono (SESSAO-56, [[handoff_2026_11_23_sessao56_busca_geoapify_ordem_da_rota|handoff]]).
