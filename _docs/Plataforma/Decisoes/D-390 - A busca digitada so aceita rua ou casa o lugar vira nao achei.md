# D-390 · A busca digitada só aceita rua ou casa; o lugar vira "não achei" com onde abrir o mapa (24/11/2026, SESSAO-57)

No endereço digitado ("Achar no mapa" da parada avulsa, "Ajustar o pino"/"Marcar no mapa" e "Editar endereço"), só **rua ou casa** vira o ponto. Se o texto começa por uma rua, o nome do resultado precisa ser parecido com ela. Quando o mapa só acha o **bairro** ou a **cidade**, a resposta é "não achei" com o lugar junto — a janela abre o mapa ali, com o aviso âmbar "Não achei a rua no mapa — o pino está no bairro …". Do pedido do dono (SESSAO-57, [[handoff_2026_11_24_sessao57_pino_certo|handoff]]).
